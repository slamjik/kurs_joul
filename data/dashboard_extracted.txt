Обзор системы
Дашборд оценки качества обучения — интерактивная аналитическая система для руководства филиала ВУЗа, реализующая сквозную логику погружения в данные (Drill-down) от общего коэффициента филиала до персональной карты преподавателя.
Назначение и целевая аудитория
Система предназначена для Директора и Декана филиала и позволяет в режиме реального времени отслеживать качество учебного процесса на основе анонимных анкет студентов. Дашборд визуализирует данные 250 виртуальных студентов по 10 преподавателям, распределённым по 4 кафедрам.

Структура HTML-файла
Файл dashboard.html состоит из четырёх логических блоков:
<head> — подключение зависимостей (Tailwind CSS, Chart.js, Google Fonts) и блок кастомных CSS-стилей с анимациями.
<header> — фиксированная шапка с логотипом, хлебными крошками (breadcrumb) и индикатором Live.
<main> — пять скрытых <div id="screenN">, из которых в каждый момент активен ровно один.
<script> — блок JavaScript: массивы данных, функции навигации, рендеринг плиток, графиков и персональных карт.

Навигация и экраны дашборда

Полный исходный HTML-код
Файл dashboard.html состоит из четырёх логических секций: HEAD (зависимости и стили), HEADER (шапка), MAIN (пять экранов) и SCRIPT (данные и логика). Ниже каждая секция описана с указанием ключевых атрибутов и значений.
Секция HEAD — зависимости и стили
Тег DOCTYPE и корневой элемент: DOCTYPE html, html lang="ru".
Мета-теги: charset UTF-8, viewport width=device-width initial-scale=1.0.
Заголовок страницы: «Дашборд качества обучения — Филиал ВУЗа».
Внешние скрипты, подключаемые через CDN:
Tailwind CSS: https://cdn.tailwindcss.com
Chart.js 4.4.0: https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js
Шрифт Inter подключается через Google Fonts с весами 300, 400, 500, 600, 700, 800.

Адаптация дашборда под реальные данные
Для замены синтетических данных на реальные необходимо отредактировать JavaScript-константы в блоке <script> файла dashboard.html:
BLOCKS — обновить значения index для каждого блока анкеты.
DEPT_DATA — обновить массив values с реальными индексами кафедр.
DEFECTS_MATH / DEFECTS_ALGEBRA — обновить pct (процент студентов) и critical (критичность дефекта).
COMPLAINTS_MATH / COMPLAINTS_ALGEBRA — заменить тексты анонимных цитат.
Для добавления новых преподавателей или кафедр — расширить соответствующие массивы данных и HTML-разметку экранов 3 и 4.
СОВЕТ  Все данные сосредоточены в начале блока <script> и снабжены комментариями. Редактирование не требует знания HTML или CSS — достаточно изменить числовые значения в константах.
